Primary reference: https://docs.nvidia.com/cuda/parallel-thread-execution/index.html#constant-expressions
Related sections: integer-constant-expression-evaluation; summary-of-constant-expression-evaluation-rules

Paraphrased requirements: PTX constants carry s64/u64/f64 types. Each floating arithmetic operation uses binary64 rounding. Integer expressions define precedence, signed/unsigned conversions, wrapping/casts, logical and comparison results, and conditional branch typing. Casts between integer and floating types are excluded. Raw single-precision bit constants cannot enter expressions.

The summary and prose differ on some result-type statements, and toolkit observations differ across CUDA 12.8 builds. Unresolved cases are recorded explicitly and reject in the admitted domain; see first-hardware-failure-audit.json and candidate-oracle-gate.json.
