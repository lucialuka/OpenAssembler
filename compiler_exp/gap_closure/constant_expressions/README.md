# G11 typed constant expressions

Status: implemented for bounded typed scalar operand expressions.

The preceding [literal cycle](../float_literals/README.md) retained seven valid
ptxas expressions rejected by OA. `baseline-parse.py` freezes that production
parser, and `baseline.json` retains rejection of all six new source families.
The canonical dossier is [scalar/literal semantics](../../../docs/compiler/gaps-wide.md).

`expression_helpers.py` implements tokenization and a Pratt parser over typed
s64/u64/f64 values; it never evaluates host-language source. Integer expressions
have explicit precedence, 64-bit wrapping, signed/unsigned casts/conversions,
truncating division, comparisons, bitwise/logical operations and same-type
integer conditionals. Floating operations round each intermediate in binary64
before the existing use conversion. Token count and nesting reject explicitly.
Source variables, general memory-address expressions, constant declarations/module
initializers and general PTX parsing remain separate work.

`candidate.py` emits self-contained `candidate-parse.py` and stages only changed
functions while retaining existing operand classes. Integer expression results
in floating operand contexts reject, instead of being used as raw float bits.
Raw32 constants retain the preceding single-literal path but cannot participate
in arithmetic expressions.

The oracle corpus retains 183 expression and eight use-context controls, with
complete tool output and accepted binaries/listings. `oracle-values.json`,
`extra-values.json` and `edge-values.json` execute accepted ptxas listings in
normal/poisoned CPU runs. Their folded bits are observations, not an independent
mathematical reference. `reference.py` separately generates typed syntax trees
and evaluates integer semantics and rational per-operation binary64 rounding.
The 4,000-case `candidate-offline.json` compares that independent reference with
the parser. Complete `execution-offline.json` passes 432 PTX/normal/poisoned
executions over six sources, all four compiler levels, lengths 0/19/32 and two
seeds, with full output/input/guard checks.

The first 108 probes exposed count masking for constant shifts, usual integer
bitwise conversions, and oversized integer wrapping. `first-expression-helpers.py`
and `first-differences.log` retain the initial wrong hypotheses. Additional
controls expose differences between the public summary table and this toolkit:
mixed signed/unsigned conditional branches and remainder by zero now reject
explicitly. Floating conditional branches are rejected by the toolkit as well.

The first A100 report `candidate-a100-20261123T130725Z.json` remains **failed**:
384 launches include 48 ptxas control failures, with OA matching the independent
reference throughout. `first-hardware-failure-audit.json` checks 40,304,640 full
bytes using exact frozen sources and finds two cross-toolchain differences:
remainder-result signedness and the sign of a NaN generated by invalid infinity
arithmetic. Local ptxas V12.8.61 and worker V12.8.93 differ. The admitted grammar
now requires an explicit signed/unsigned cast before a remainder result enters
further arithmetic and rejects invalid NaN-producing constant arithmetic until
the payload contract is reconciled. Standalone remainder with nonzero divisor
and explicit NaN-operand propagation remain separate tested cases. This is a
documented unresolved boundary, not a rewritten passing first gate.

The first isolated install omitted the changed operand-context helper while
the standalone candidate already contained it. `first-install-candidate.py`
and `candidate-oracle-audit-first.log` retain that harness failure. The final
staging installer includes every changed helper. A NaN numerator over zero
also exposed an error-check ordering issue before final source freeze;
`candidate-oracle-gate-first.log` retains it. All final gates must bind exact
candidate bytes and preserve the failed reports.

The final A100 report `candidate-a100-20261123T131948Z.json` passes **384 launches**
on A100-SXM4-40GB, driver 13030, Python 3.12.1 and ptxas V12.8.93. Six fixtures
use all four OA levels, same-PTX ptxas controls, three 128-thread CTAs, lengths
0/1/259/384 and two input seeds. The independent production audit rechecks
40,304,640 retained bytes and twenty-four current native comparisons with
exact source/ownership/frame/register custody. The 204 focused tests pass.
Production imports no experiment module and its parser bytes equal the final
hardware candidate. No failed first report is included in those passing counts.

The earlier passing `candidate-a100-20261123T131225Z.json` predates a conditional
depth guard. `depth-baseline.json` found that long conditional chains could
reach Python RecursionError while parentheses/unary nesting was bounded. The
final guard counts recursive expression levels too. `depth-repair.json`, an
extended regression and the new exact-source A100 report bind that repair.
The earlier passing suites/native replay remain in `pre-depth-*` files; final
integration reruns against the revised parser bytes.

The first candidate byte auditor imported the preceding literal cycle's staging
helper because a reference import prepended that directory to the search path.
`first-audit.py` and `candidate-audit-first.log` retain that harness failure.
The final auditor explicitly restores its own directory before loading the
staged parser and captures its source hash at module load. Neither production
nor hardware source bytes needed changing for that audit repair.

`run_modal.py` captures the harness hash before dispatch, runs all four levels
with same-PTX ptxas controls, and retains complete input/output/guards/tails,
manifests, resources, native code and disassembly. `audit.py` captures its own
source hash at module load and rechecks complete bytes plus regenerated native
words/resources/ownership. No timing claim is made. Full suites, 49-policy
continuity, application continuity and docs checks precede final integration.
Broad G11 and the original 51-gap program remain incomplete.

The final hardened-source suites pass 3,042 supported tests and 2,557
compiler-only tests with 15 explicit skips. The final parser/test/evidence
identities, live/exported documentation, 49-policy continuity and 1,498 prior
native occurrences are bound in `validation.json`.
